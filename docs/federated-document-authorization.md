`src/m365/federated-document-reader.ts` composes independently verified fresh human login, a signed registered-agent assertion, authoritative current consent, a separately verified document proof, and the constrained Graph adapter. It accepts only the operator-pinned synthetic document and expected hash. Entra app-only authority remains the broker's; no external human Entra identity is created.

The document proof audience is `api://federated-copilot/documents`, its sole scope is `m365.document.read`, and its maximum lifetime is 60 seconds. The registered agent assertion uses `api://pf-a/document-agent-proof` and a pinned public key with a maximum 120-second lifetime. These are separate from existing `copilot.invoke` authority. Login issuer/audience/subject provenance is retained alongside the human, actor, organisation, grant and execution mode. Only interactive execution is implemented here.

The trusted `createDocumentConsentPolicy` adapter requires a recorded, login-bound consent issued by `policy-document-consent`, exactly the document capability and interactive mode, and a positive grant duration no longer than five minutes. The policy store permits explicit trusted configuration `consentDurationsSeconds: [300]`; its existing default remains one hour or one day. This option is not a client-controlled request field. No running policy service has been reconfigured.

A separate SQLite journal claims each grant before issuance, serializes pending work across controllers, and retains spent grant digests. Success is withheld until independent grant revocation is confirmed. Failed cleanup retains a pending recovery record and blocks new reads; recovery can only revoke the owned consent and requires no new token or document request. Recovered identifying metadata can be pruned after one day, while pending recovery evidence and spent digests remain. The journal checks a 2 MiB bound at opening; it is not a complete deployed retention/rotation service.

Before each network boundary and release, the reader repeats the human/agent and current grant checks. The shared transport continues to pin site, drive, item, file identifiers, version and download destination. Tokens, document text and signed download URLs are not persisted by this controller. Returned text is marked untrusted document content. The initial profile intentionally restricts output to the known synthetic sample's exact byte length and hash.
